# Kishore B - AI & Data Engineering Portfolio

Personal portfolio highlighting work in agentic AI, retrieval-augmented generation, data engineering, analytics, and enterprise software.

## Preview locally

This is a static site; no build or package installation is required.

```powershell
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in a browser.

The published page is `index.html` at the repository root. Styles, scripts, and media are served from the adjacent `css/`, `js/`, and `images/` folders.
